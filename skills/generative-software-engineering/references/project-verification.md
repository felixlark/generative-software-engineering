# 项目验收地图衔接

多入口验收需要复用方法时，按[验收技能路由](skill-routing.md#理解调试与设计)调用当前 pstack 验收叶技能，在项目自身维护地图。

可复用[地图模板](feature-map-template.md)承载项目信息。项目控制面、真实安装版本、设备及授权由当前合同决定；地图存在与实际逐项通过分别举证，规范归[证据要求](https://github.com/felixlark/generative-software-engineering/blob/main/docs/EVIDENCE.md)。

归因与历史适配许可见[方法来源](method-sources.md)。
