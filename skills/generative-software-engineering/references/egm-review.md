# EGM 方案审查入口

方案新拟、实质修订或用户明确要求完整 EGM 流程时，按[方案审查路由](skill-routing.md#方案审查)调用当前 EGM 技能。角色、标准、复审与收敛条件归该技能。

GSE 提供稳定候选与必要来源，核实发现后在原授权内继续交付；有效审查证据按[协作规范](https://github.com/felixlark/generative-software-engineering/blob/main/docs/COLLABORATION.md#review-scope-and-evidence-reuse)复用。

归因与历史适配许可见[方法来源](method-sources.md)。
